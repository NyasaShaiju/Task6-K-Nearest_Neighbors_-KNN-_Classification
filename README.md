# Task6-K-Nearest_Neighbors_-KNN-_Classification
This task demonstrates the implementation of the K-Nearest Neighbors (KNN) algorithm using the Iris dataset. The goal is to classify iris flower species based on petal and sepal features.
Key Highlights:
Dataset: Iris dataset (150 samples, 3 classes)
Preprocessing: Feature normalization using StandardScaler
Model: KNeighborsClassifier from Scikit-learn
Evaluation: Accuracy score and confusion matrix
Visualization: Accuracy vs. K plot and decision boundaries (2D)
